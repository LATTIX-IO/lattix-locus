Version: 0.2

Lattix Locus 0.2: the unified single-user desktop app, Deep Agents as the
default runtime and the Dev / Stable update channels. Builds are now numbered
0.2.0, 0.2.1, ... (one number per published build, D-31) and rank above every
0.1.0-dev.N Dev build and the 0.1.1 Stable, so existing installs update forward.
Windows ships the NSIS installer only; the MSI installer is no longer built.
