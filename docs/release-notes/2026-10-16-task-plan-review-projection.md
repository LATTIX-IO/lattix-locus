Release-Impact: minor
Version: 0.8

Adds a versioned, non-executable TaskPlan review projection to the backend library. Future plan review surfaces can display bounded proposals against server-owned context without implying policy authorization or starting work. No public plan endpoint, new grant, or automatic data migration is introduced.

Action required: None. A later, separately reviewed increment must implement authenticated plan review receipts and Gateway-bound execution before this preview can be used to start tasks.
