Target-state design

One application for delegating any digital work to governed AI.

A clickable prototype covering the seven primary areas, the global shell and onboarding. Each surface is marked with its implementation status against the current Locus repository so that target-state design never reads as shipped capability.

Simulated demo · not connected to the Locus backend. v0.3.1 stabilizes the design baseline: one run-state contract, complete agent definitions with evaluation and rollback, handoff checks, and untrusted-data rendering on every screen. Reset state from the command palette.

Screens in this prototype

Shortcuts: Ctrl K search · I inbox · G then H/W/A/L/M/C/S to navigate · [ collapse nav
00 · /auth, /onboarding

Sign in & setup

Verified local identity, tenant session, reauthentication and step-up as separate steps; then runtime choice with live checks, available models, default autonomy.

Foundation 01 · /home

Home

Task composer that infers a plan: who, what data, which tools, when you'll be asked. Decisions, running work, outcomes.

Existing, extended 02 · /work/*

Work

Tasks (list, board, dependencies), projects (milestones, people and agents, memory scope), schedules (14-day calendar, unattended rules, history), conversations.

Planned area 03 · /activity/runs

Activity · live run

Conversation between you and agents with steering, agent-to-agent threads and reasoning summaries. Trace with event inspector, reasoning (goal, evidence, assembly, commitment), policy decisions, approval, checkpoints.

Existing, extended 04 · /library

Library

Agents and teams, workflows, MCP lifecycle, A2A peers, skills. Each entity defined distinctly with its own governance.

Existing, extended 04a · /library/agents/:id

Agent builder

Engine, model route, ceiling, skills, permissions and limits; draft, publish checks, versions.

Planned 04b · /library/teams/:id

Team composer

Members, lead, per-member delegated authority, handoffs and limits. Authority never widens through a team.

Planned 05 · /memory

Memory

Scoped records with provenance and trust, collections, contradiction resolution, write and retention governance.

Foundation 06 · /control-tower

Control Tower

Fleet topology and node health, model routes, engine mediation, policy operations, evaluations, improvement proposals.

Planned area 07 · /settings

Settings

Preferences, members and roles, identity, secrets, computer-use tiers, deployment, audit export.
