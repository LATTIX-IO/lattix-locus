Operating modes

The mode is a frame on every page: a band on the top edge plus a labelled pill. Never colour-only.

Observation

Read-only telemetry. Neutral band.

Simulation

No enforcement or equipment connection. Hatched violet band.

Governed execution

Commands reach live systems. Solid red band; entering requires confirmation.
